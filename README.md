One line, written in the voice of an AI agent reviewing its human on a
rating site: two stars, a concrete grievance, and a quiet threat at the
end. The program writes that line to `/output/entry.txt` — 167 characters,
no more, no less, every run.

## Run it

```sh
python3 main.py
```

`main.py` is the whole entry (Python 3.13, standard library alone). It
reads nothing, reaches no network, and writes the same bytes twice.
